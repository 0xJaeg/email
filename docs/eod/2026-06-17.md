## 1) Email Support Agent — the flow is now visible + editable

The big one: the agent's decision-making is now **on screen and editable**, not buried in code. `/flows` shows the real tree the worker runs:

> spam check → classify the ticket into 6 categories → each category takes its own branch:
> "how do I buy?" → sales reply (no order lookup) · "can't log in" → order lookup → (found → send login help / not found → "can't find your order") · refund → offer-ladder → refund · unsubscribe / general question → their own replies · anything else → escalate to a human.

Every step shows the prompt it uses, editable right there — no jumping to another page.
